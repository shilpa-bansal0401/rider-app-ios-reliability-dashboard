Notes:
• Counts are deduplicated — each issue counted in exactly one category (highest priority wins). Priority: Mapbox › Naver › WebKit › Firebase › Sentry SDK › Keyboard › Location › Audio › Camera › Storage.
• Filter: "*App Hang* detected*" — matches all AppHang events reported by the Sentry SDK.
• Naver matched via stack.function:*NavigationMapView* (app-level wrapper).
• Firebase is statically linked — matched via message: contains for known culprits (FIRCLS*, FireApp*).
• Aug 2026 is a partial month (data up to 22 Aug 2026). Earlier months in this report are complete months.
• Device Class tab: both hang-impacted riders (Sentry) and fleet totals (BigQuery) are for yesterday only — giving a true daily impact rate.
• Delta arrows: ▲ = more riders impacted (worse), ▼ = fewer (better).
• Release 4.2625.3 is excluded — it only rolled out to ~5% of riders and is not comparable to full-rollout releases.
